# Voidamp releases

Public signed releases of Voidamp, a native macOS menu bar audio mixer.

Download the latest app from [Releases](https://github.com/lumen-xx/voidmap-releases/releases/latest).

Requires macOS 14.2 or newer and an Apple silicon Mac. Existing updater-enabled installations can use **More → Check for Updates…**. First-time installation may require macOS approval because the app is not Apple notarized.

This repository contains only release files and the signed Sparkle update feed. The source repository is private.
